# TV Latam

Canales en vivo de Latinoamérica, España e internacionales, agrupados por género.

Incluye una lista propia (más de 140 canales). Opcionalmente puedes indicar la URL de otra lista M3U en la configuración del repositorio.

## Categorías

Deportes, canales abiertos, regionales, noticias, cine y series, novelas, documentales, estilo de vida, infantil, música, religiosos y otros.

## Instalación

1. Carga `plugin.js` como código del repositorio.
2. Usa `manifest.json` como base del manifiesto.
3. (Opcional) En configuración del repo, campo **lista**: URL de un `.m3u` externo.

## Notas

- Los ítems usan `type: "channel"` para TV en vivo.
- No se incluyen canales para adultos.
- La disponibilidad de cada stream depende del servidor de origen.
